# SKRIPTA — koncept proizvoda &amp; vizija

Samostalni, statički one-pager koji predstavlja **SKRIPTA** — open-source platformu za učenje ulaganja na hrvatskom. Besplatno za sve, premium tek kasnije i dobrovoljno.

> Brojke, ne priče. Burza objašnjena kao da ti je kolega šalje skriptu prije ispita.

## Što je ovo
Pitch / vizijski dokument (nije investicijski savjet). Prati narativ:
**Problem → Rješenje → Proizvod (Grafovi · Lekcije · Simulator) → Tržište → Model → Plan → Vizija.**

## Pokretanje
Nema builda, nema ovisnosti — čisti HTML + inline CSS/SVG.

```bash
open index.html        # ili dvoklik
```

## Napomene
- Sve brojke u sekciji **Tržište** su **ilustrativne pretpostavke**, ne provjereni podaci.
- Brend (boje, znak od 10 kockica, glas) naslijeđen je iz originalnog brand koncepta v2.
- Dizajniran kao samostalan projekt — može se izdvojiti u vlastiti repozitorij bez izmjena.
